# 🎓 Carterinha Universitária - Simulador

Um aplicativo web para simular uma carterinha de identificação estudantil universitária.

## 📋 Funcionalidades

- ✅ Formulário completo para dados do estudante
- ✅ Prévia em tempo real da carterinha
- ✅ Upload de foto ou URL de imagem
- ✅ Design responsivo para mobile e desktop
- ✅ Impressão da carterinha
- ✅ Download como imagem
- ✅ Dados de exemplo para teste
- ✅ Interface em português brasileiro

## 🚀 Como usar

1. Abra o arquivo `index.html` em seu navegador
2. Preencha os dados do estudante no formulário
3. Adicione uma foto (arquivo ou URL)
4. Clique em "Gerar Carterinha" para visualizar
5. Use os botões para imprimir ou baixar a carterinha

## 📱 Tecnologias utilizadas

- **HTML5** - Estrutura da aplicação
- **CSS3** - Estilização e design responsivo
- **JavaScript** - Funcionalidades interativas
- **html2canvas** - Geração de imagem para download

## 🎨 Características do design

- Layout inspirado em carteirinhas universitárias reais
- Cores institucionais e design profissional
- Foto do estudante com bordas arredondadas
- Informações organizadas de forma clara
- QR code placeholder para validação futura
- Data de validade automática

## 📐 Estrutura dos arquivos

```
Carterinha-/

```

## 🔧 Personalização

Para personalizar a carterinha, você pode modificar:

- **Cores**: Edite as variáveis de cor no arquivo `style.css`
- **Logo**: Substitua o emoji 🏛️ por uma imagem real
- **Campos**: Adicione novos campos no formulário e na carterinha
- **Validação**: Modifique as regras de validação no `script.js`

## 🌐 Demonstração

O aplicativo funciona completamente offline após o primeiro carregamento e é responsivo para diferentes tamanhos de tela.
